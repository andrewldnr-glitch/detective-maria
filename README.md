# ДЕЛО № 08-11: Похищение конверта (v4 — Живой стол + встроенная GIF)

Готовый проект детективного квеста ко Дню рождения Марии для размещения на GitHub Pages.

## Что уже внутри:
* **Дизайн «Живой стол»:** матовая тёплая архивная бумага, пометки карандашом на полях, 6 разноформатных улик (блокнотный листок, полароид, кассета VHS, кинобилет, радиоперехват, крафтовый конверт), провисающие красные нити и эффект фотонегатива для закрытых улик.
* **Экран загрузки с GIF:** в папку `assets/` уже вшит готовый анимированный файл `detective.gif` с образом Детектива Марии.
* **Обложка для бота:** в `assets/bot_cover.jpg` также лежит квадратная витрина для установки на аватарку бота в `@BotFather`.

## Что осталось заменить своими файлами в `assets/`:
1. `assets/bgm.mp3` — твоя фоновая детективная музыка (автоматически замолкает на время проигрывания голосовых).
2. `assets/stage1.mp3` — `assets/stage6.mp3` — твои 6 голосовых сообщений.
3. *(По желанию)* `assets/photo1.jpg` — `assets/photo6.jpg` — фотографии для полароидов внутри карточек.
